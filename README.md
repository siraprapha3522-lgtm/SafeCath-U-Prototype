# SafeCath U - by SafeCath Innovators
> สังเกตความเปลี่ยนแปลง เพื่อการดูแลที่ใส่ใจยิ่งขึ้น | MEDiHack 2026

### ทีม SafeCath Innovator
- สมาชิก 1: ชีววิทยา - วิเคราะห์สภาวะปกติ/ผิดปกติ
- สมาชิก 2: เคมี/อิเล็กทรอนิกส์ - ต่อ Flow Sensor + ท่อจำลอง
- สมาชิก 3: วิเคราะห์ข้อมูล - กราฟ Flow Rate แบบต่อเนื่อง
- ที่ปรึกษา: คุณครูชีววิทยา

### ปัญหา
ผู้สูงอายุที่ใส่สายสวนปัสสาวะมีความเสี่ยงเกิดภาวะแทรกซ้อน หากไม่สังเกตการเปลี่ยนแปลง

### แนวคิดใหม่
ไม่ได้ดูแค่ค่าจุดเดียว แต่ศึกษาการเปลี่ยนแปลงของข้อมูลอย่างต่อเนื่อง เพื่อแยกสภาวะปกติกับสภาวะจำลองที่ผิดปกติ

### สิ่งที่ทำแล้ว
- [x] สร้างท่อจำลองสายสวนด้วยสายยางซิลิโคน
- [x] ทดสอบ Flow Sensor YF-S201 อ่านค่าได้
- [x] แสดงผล Flow Rate (mL/min) บน Serial Monitor / LCD
- [x] วิเคราะห์กราฟเปรียบเทียบ Normal vs Abnormal

### แผนพัฒนา Prototype
สัปดาห์ 1: ปรับสูตรคำนวณอัตราการไหล
สัปดาห์ 2: เพิ่มระบบแจ้งเตือนเมื่อ Flow < 20 mL/min นาน > 30 วินาที
สัปดาห์ 3: บันทึกข้อมูลต่อเนื่อง (Data Logging)
สัปดาห์ 4: ทำกล่องต้นแบบ SafeCath U V1
